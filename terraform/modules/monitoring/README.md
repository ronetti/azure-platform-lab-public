# Monitoring Module

## Deutsch

Dieses Basismodul erstellt die Monitoring-Grundlage mit Log Analytics. Es ist
die technische Basis für Diagnose, handlungsrelevante Alerts und
Availability-Engineering-Signale.

Retention, Diagnostic Settings und SLI-nahe Signale sollten über Konfiguration
und Reviews steuerbar bleiben. Monitoring ist Teil des Betriebsmodells, nicht
nachträgliche Dekoration.

## English

This baseline module creates the monitoring foundation with Log Analytics. It
is the technical basis for diagnostics, actionable alerts and
availability-engineering signals.

Retention, diagnostic settings and SLI-related signals should remain
controlled through configuration and reviews. Monitoring is part of the
operating model, not an afterthought.
