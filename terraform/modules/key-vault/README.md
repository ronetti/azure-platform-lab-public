# Key Vault Module

## Deutsch

Dieses Basismodul rahmt die Secret- und Zertifikatsbasis der Plattform. In
diesem anonymisierten Repository wird bewusst nur der Modulrahmen gezeigt.

In einer echten Plattform gehören dazu klare RBAC/IAM-Grenzen, keine Secrets in
Git, getrennte Pipeline-Berechtigungen und nachvollziehbare Zugriffe.
Änderungen an Secrets, Zertifikaten oder Zugriffsmodellen brauchen Reviews und
passende Approvals.

## English

This baseline module frames the platform secret and certificate foundation. In
this anonymized repository, only the module frame is shown deliberately.

In a real platform this includes clear RBAC/IAM boundaries, no secrets in Git,
separate pipeline permissions and access that can be checked later. Changes to secrets,
certificates or access models require reviews and suitable approvals.
